## Material differences and release disposition

- Submitted p.6 gives `2total` as INT then IDENT. Current later numeric recovery makes it one E102 INVALID run. Tests intentionally expose this difference; this release preserves the accepted current rule, not exact historical tokenization.
- Submitted slash is truncating Int division; later numerical rules make `/` real division and add Float. This scanner recognizes the symbol and numeric spelling; it does not implement or validate either runtime meaning.
- Original report category groups/location columns differ from current two-column classroom output. RESERVED_NAME maps to RESERVED_WORD; COMMENT_LINE/BLOCK map to LINE_COMMENT/BLOCK_COMMENT; broad OPERATOR/DELIMITER groups map to concrete token labels. Lossless quoting remains available without --classroom.

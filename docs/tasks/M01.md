## Implementation requirements

Create SourceId, SourceFile, SourceSpan and computed SourceLocation. Retain original bytes; validate UTF-8/BOM/CRLF; support EOF and empty files. Implement byte-to-scalar coordinate mapping and a separate tab-display mapping. SourceManager deduplicates explicitly loaded canonical paths per session and never silently rereads.

## Tests and evidence

ASCII/multibyte/NUL-in-escaped-source, invalid UTF-8, CRLF and lone CR, empty file, EOF span, span bounds, byte/scalar round trips with bounded native generators.

Use `/ternfold-feature` for the impact assessment. Use `/ternfold-differential` for execution/ownership work. Record actual observed results; do not infer success from command availability.

## Implementation requirements

Implement structured ANF blocks and typed operations, lexical dominance/tag-proof verifier, stable dumps, closure lifting and match decision trees. Lower step to generated ordinary functions with candidate schedule, ordered nested guards, and delayed output construction. Lower short circuits as If. Preserve evaluation/fault origins; no optimization. Add core CLI gated on verification.

## Tests and evidence

Golden machine/short-circuit/match/closure lowering plus structural assertions: no next/machine opcodes, payload projection proofs, scopes, all IDs defined, branch-result types. Construct invalid IR by hand to verify rejection.

Use `/ternfold-feature` for the impact assessment. Use `/ternfold-differential` for execution/ownership work. Record actual observed results; do not infer success from command availability.

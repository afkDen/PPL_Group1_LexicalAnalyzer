Status is tracked in [progress](../progress.md) and [task graph](../tasks.json). Phase: **advanced**. Prerequisites: M14.

## Objective

Improve generated execution while preserving deterministic faults.

## Implementation requirements

Add ADR and explicit optimization level. Start with safe constant folding and redundant pure non-faulting copies, then native liveness-based releases. Never remove graph errors before checking or reorder possible language faults. Benchmark compilation time, native runtime and peak memory on repeatable workloads; keep unoptimized reference available.

## Tests and evidence

Optimized/unoptimized/interpreter three-way equivalence including first faults; release-path sanitizers and allocation injection; reproducible benchmarks with metadata.

Use `/ternfold-feature` for the impact assessment. Use `/ternfold-differential` for execution/ownership work. Record actual observed results; do not infer success from command availability.

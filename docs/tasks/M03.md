## Implementation requirements

Implement explicit character-driven scanning/trie terminal metadata (never completed-word lookup), longest-match operators, comments, unsigned decimal magnitudes and Unicode string escapes. Preserve EOF. Reject leading zeros and malformed escapes; source controls/newlines follow the spec. Add tokens CLI with deterministic dump and diagnostic exit codes. Do not validate signed range before unary-minus context is known.

## Tests and evidence

Every token/keyword, multi-character adjacency, unterminated strings, malformed scalars, magnitude boundaries, no stalled recovery loops, token span ordering/coverage properties excluding trivia.

Use `/ternfold-feature` for the impact assessment. Use `/ternfold-differential` for execution/ownership work. Record actual observed results; do not infer success from command availability.

# ADR 0005: One structured Core and two executors

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

Machines and matches should lower once rather than acquire backend-specific semantics.

## Considered options

AST interpretation plus direct C; custom bytecode VM; structured Core; CFG SSA/LLVM.

## Decision

Typed AST plus inspectable MachinePlan lower into one structured ANF Core, interpreted directly and emitted structurally to C17.

## Rationale

Core removes special machine semantics, preserves control/evaluation order, and maps cleanly to C.

## Consequences

Shared lowering bugs need independent expected-result tests; no AST interpreter claim. CFG/bytecode is deferred until a clear need.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

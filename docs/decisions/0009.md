# ADR 0009 — Course-aligned additive surface revision

Status: **accepted**, 2026-10-15. Target: Ternfold 0.2, not yet implemented.

## Context

The group's Ternfold 0.1 proposal is a principled static/pure transition language. A later PPL course rubric explicitly requires exponentiation, a distinct integer division operator, noise words, multiline comments, at least four *lexical* literal types, input/output statements, and demonstrable single/nested loops, plus finite automata and a symbol-table text file. Original 0.1 intentionally lacked several of these. Misrepresenting them as already implemented would be misleading, and rewriting the machine model would erase Ternfold's identity.

## Options

1. Describe missing features only in an appendix — fails implementation/real rubric.
2. Redesign as a generic imperative language — loses transition semantics and invalidates core decisions.
3. **Add a coherent surface revision with explicit host boundary and pure comprehensions** — accepted.

## Decisions and tradeoffs

- Add `^` checked exponentiation and `div` floor integer division; `//` remains line comments. The original truncating Int `/` decision is superseded by [ADR 0010](0010.md): real division with finite binary64 Float. Lex `div` as a keyword operator and preserve explicit negative-Int rules.
- Add primitive `Char` literals and type; four independent lexical literal families now exist without pretending `()` is a single lexer token. Add `/* ... */` nonnesting comments alongside `//`.
- Add `from`/`to` as optional readability words in `input ... [from stdin]` and `output ... [to stdout]`, and reserve `stdin`/`stdout` source/sink designators.
- Add pure `for ... in ... { expr }` **list comprehensions**, including natural nesting; avoid mutable imperative for/while loops.
- Allow entrypoint-only ordered input/output clauses in root main body, lowering them to a hidden input-snapshot/privately staged output adapter. Functions and machines remain pure; main captures deterministic input at the boundary; output publication stays all-or-nothing on language evaluation failure.
- Reject non-`.tfd` source and provide a truthful deterministic Symbol Table.txt report with diagnostic classifications, lexical spans and comments, not a fake separate lexer.
- Preserve all existing immutable machine graph scheduling, old/candidate semantics, typed ordered guards, single-writer invariant, C17 backend, Python host and static type architecture. Extend Core/ABI only as required.

## Consequences

The parser, types, coverage, Core, interpreter, C runtime/backend, tests and docs must be extended coherently. M01–M04 already implemented in an earlier *different* working session are not imported into this restart snapshot; this foundation starts M01. These are target semantics only until tests and actual execution pass. Course rubric terms such as input/assignment/loop are satisfied through explicit, deliberately constrained language constructs, not Python/C host cheats. See `docs/course-requirements.md`, `docs/automata.md`, `docs/language-spec.md`, `docs/grammar.md`.

## Implementation clarification — 2026-10-27

M06 preflight identified that the minimum-Int magnitude exception was stated for
expressions while the grammar separately permits signed literal patterns. The
range rule is now explicit for both: only contiguous minus/magnitude grants the
9223372036854775808 exception. Whitespace/comments do not widen the permitted
magnitude, and smaller negative patterns retain normal free-field syntax.
Patterns have no parenthesized grouping production. This keeps one signed
literal domain and uses the separate minus/literal origins already preserved by
M04. M06 must add accepted, gap/comment, positive-overflow and smaller-negative
pattern regressions; independent semantic review checks this clarification.

## Host-entry clarification — approved 2026-10-28

The human explicitly selected entry-only behavior for a root public main whose
outer body contains input or output clauses. Source references to that resolved
function identity are E208, including ordinary calls, function values, recursion,
closures and machine expressions. A main without I/O clauses remains an ordinary
callable function. The hidden host adapter has no source-visible symbol. This
closes the previous undefined ordinary-call I/O case without introducing ambient
I/O into pure functions. Shadowed/unrelated main binders remain unaffected.

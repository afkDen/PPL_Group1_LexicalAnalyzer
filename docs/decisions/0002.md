# ADR 0002: Immutable guarded transition values

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

State updates need a recognizable semantic center with meaningful compiler work.

## Considered options

Pure record updates; mutable transactional cells; clocked synchronous nodes; immutable machines.

## Decision

Nominal immutable machines with old/proposed reads, exactly one writer, typed ordered guards and delayed emissions.

## Rationale

The graph and acceptance boundary become explicit without concurrency or rollback runtime.

## Consequences

step returns ordinary Accept/Reject data; faults remain separate; initialization is not guard-validated; domain decisions are forgeable ordinary values.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

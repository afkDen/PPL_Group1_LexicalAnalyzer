# ADR 0004: Handwritten recursive descent and Pratt parsing

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

The grammar has declarations, blocks, patterns and operator expressions, without indentation semantics.

## Considered options

Parser generator, all recursive descent, Pratt plus recursive descent.

## Decision

Use recursive descent for structural forms and Pratt for expressions; exact recovery rules in grammar.md.

## Rationale

Transparent source spans and error recovery; no hidden grammar generation dependency.

## Consequences

Tests must cover precedence, nonassociative comparisons and parser progress; named record arguments remove brace ambiguity.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

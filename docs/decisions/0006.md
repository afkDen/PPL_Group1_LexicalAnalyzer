# ADR 0006: C17 backend and acyclic reference counting

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

Native programs should be self-contained without a heavyweight compiler dependency or tracing collector.

## Considered options

C17, WebAssembly, LLVM, VM; arena-only memory, tracing GC, RC.

## Decision

Structured C17 with boxed immutable acyclic aggregates and checked RC; borrowed arguments, owned results; iterative destruction.

## Rationale

Ordinary native tools plus explicit checked runtime preserve semantics. Immutability and absence of cyclic closures simplify reclamation.

## Consequences

Ownership is the main backend risk. Conservative function-local slot cleanup first; sanitizer/allocation-failure tests required before liveness optimization.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

# ADR 0008: Local modules and explicit driver output

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

Builds should be reproducible offline and pure computations should not acquire ambient authority.

## Considered options

Online package resolution, implicit path search, local explicit import roots; effectful main or buffered returned output.

## Decision

Root-contained relative imports, explicit aliases, import DAG, whole-program compilation; main returns List[Text] for the driver.

## Rationale

Source dependency graph and observable boundary stay small and inspectable.

## Consequences

No OS/network APIs in language 0.1; fresh dependency install needs package access but compilation/execution do not. REPL is a host session, not new effects.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

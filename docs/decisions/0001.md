# ADR 0001: Python host and an offline toolchain

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

The frontend must be easy to evolve and inspect in future autonomous coding sessions.

## Considered options

Python, Rust, OCaml, TypeScript.

## Decision

Python 3.12–3.14 with stdlib-only production dependencies; uv-locked development tooling.

## Rationale

Explicit algebraic node models and fast tests outweigh frontend speed today.

## Consequences

Strict mypy/Ruff required; host numeric/Boolean semantics must not leak. Optimize or port only after measurements.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

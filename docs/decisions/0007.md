# ADR 0007: Lexical candidate graph and stable scheduling

Status: accepted for target 0.1. Date: 2026-09-13.

## Context

Independent candidates can fault; an unspecified topological order would make results unstable.

## Considered options

Source-order evaluation; dynamic dependency evaluation; input-sensitive graph; lexical DAG with stable ready-name order.

## Decision

Collect lexical next projections before optimization; reject any cycle; repeatedly choose smallest ASCII ready cell name.

## Rationale

Simple predictable compile-time analysis and writer-declaration permutation invariance.

## Consequences

Some conditionally safe cycles are rejected; renaming can affect first fault. Guards execute after all candidates and cannot protect candidate faults.

This ADR explains the commitment; precise current semantics belong to the focused specification. Update or supersede this record when changing that commitment, and link the new record here.

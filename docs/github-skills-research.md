# Project-skill provenance

The nine project-local skills are original offline Ternfold procedures, adapted
for C17 in ADR0011. They are not falsely labeled as verbatim upstream packages.
Historical research details remain in history/python-full-2026-10-28. The prior
quality workflows considered https://github.com/obra/superpowers (test-driven
development, systematic debugging and verification-before-completion). Current
procedures add native ownership, allocation failure, UB, phase invariants and
independent review. No installed skill or hosted API is a compiler dependency.

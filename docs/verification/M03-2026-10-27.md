## Current scope

`tokens.py`, `lexer.py`, `lexical_report.py`, the `tokens` CLI command,
`tests/test_lexer.py`, CLI tests and lexical fixtures are under implementation.
Int magnitude payloads are canonical decimal strings in `DecimalMagnitude`;
JSON uses an explicit decimal object, so Python's decimal conversion limit does
not become lexical policy. Signed bounds remain M06 work.

The scanner retains actual tokens, INVALID recovery tokens, EOF and trivia.
`LexResult.for_parser()` returns an error result if any lexical error occurred,
including suppressed errors. The course report is a view over those exact
tokens/trivia, with reserved/noise overlays and additional Unit-shaped composite
rows; it does not claim parser or semantic validity.
